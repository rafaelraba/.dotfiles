# Hammerspoon

Hammerspoon owns only global keyboard input helpers.

It must not manage windows, layouts, workspaces, SketchyBar, AeroSpace, app launchers, or frame geometry.

## Shortcuts

| Hotkey | Output |
|--------|--------|
| `Ctrl+Option+N` | `ñ` |
| `Ctrl+Option+Shift+N` | `Ñ` |
| `Ctrl+Option+E` | Starts acute-accent mode for the next vowel |

Use `Ctrl+Option+E`, then a vowel, to compose characters such as `á`, `é`, `í`, `ó`, and `ú` globally. Holding Shift for the vowel emits the uppercase version.
