# Raycast

Raycast owns one-shot floating-window placement. AeroSpace still owns workspaces, tiling, and floating/tiling state.

## Restore

1. Open Raycast and grant Accessibility permissions.
2. Configure the desired Window Management command and hotkey in Raycast.
3. On another machine, import your Raycast `.rayconfig` backup if available.

## Exported settings

Raycast can export settings, aliases, hotkeys, and Window Management layouts to an encrypted `.rayconfig` file. Use that for backup or migration between machines.

This directory intentionally does not include a custom Script Command for window placement; the workflow should stay native to Raycast.
